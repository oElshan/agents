# Project Summary

> Сжатая выжимка архитектуры проекта (~500 токенов). Генерируется `/init` из
> ARCHITECTURE.md / README / скана репо, поддерживается architect'ом. Агенты читают ЭТОТ
> файл вместо полного ARCHITECTURE.md.

**Статус: не инициализирован — запусти `/init`.**

## Что здесь должно быть (после /init)

- Назначение системы в 2-3 предложениях
- Топология: список сервисов/модулей + их зоны ответственности (из project-profile.md)
- Ключевые потоки данных (кто кого вызывает, sync/async)
- Основные таблицы/агрегаты и их владельцы
- Внешние интеграции
- Нестандартные решения, о которых должен знать каждый агент
