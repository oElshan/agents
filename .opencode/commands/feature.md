Создай карточку фичи по описанию ниже.

1. Загрузи skill `board`.
2. Проверь дубли среди карточек и `docs/specs/`. Нашёл похожую: покажи её и спроси, создавать
   ли новую.
3. Создай карточку по `feature-template.md` из skill `board`: `type: feature`, `status: Backlog`.
   Бизнес-ценность, сценарии и высокоуровневые критерии сформулируй из описания. Чего в
   описании нет (метрика успеха, роли, числа нагрузки), не выдумывай: оставь вопрос в
   разделе и перечисли эти вопросы мне.
4. Режим `github`: push карточки (skill `github-sync`).
5. Ответь: id, путь к карточке, вопросы. Напомни: в работу фичу берёт `/sprint add <id>`.
