# Arch doc фичи

Шаблон: `arch-template.md` рядом с этим файлом. Файл: `docs/arch/<F>-<slug>.md` (тот же
slug, что у spec).

## Обязательные разделы для G2

1–12 всегда. 13, если `infra.orchestration: kubernetes`. 14, если `quality.high_load: true`.
15, если фича затрагивает frontend. Раздел без содержания закрывается строкой
`N/A: <причина>`.

Разделы 2, 3, 4, 5, 6, 7, 10, 12 детализируют слоты SDC из spec. Если детализация
расходится со слотом, это либо ошибка в spec (опиши в отчёте, исправит analyst), либо
архитектура не выполняет требование (исправь arch doc).

## ADR

ADR обязателен, если фича:
- добавляет модуль, сервис, внешнюю интеграцию, очередь, БД или кэш-технологию;
- добавляет слой абстракции, а в модуле их уже не меньше трёх;
- добавляет библиотеку в shared-contracts;
- упирается в порог из `docs/arch/budget.md`.

В ADR минимум две альтернативы, и одна из них «расширить существующее». Интерфейс с одной
реализацией «на будущее» не вводится.

## budget.md и ownership-map.md

Проверь, что analyst внёс новые ресурсы. Пропущенное допиши сам в том же коммите, что и
arch doc.

## Миграции

Загрузи skill `db-migration`. В arch doc описываются только новые файлы миграций.
Существующие применённые миграции не меняются.

## Доказательства

- Consumers затронутых DTO и endpoints: реальный вывод `grep -rn` (сокращённый).
- Существующие паттерны: ссылки на 1–2 файла, которым следует решение.
