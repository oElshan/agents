# История изменений

## v2.0.0 — 2026-11-01

Версия добавляет исполняемые проверки качества и меняет формат профиля проекта.
Для обновления с 1.x нужна миграция настроек.

### Что изменилось

- Проверки SHA, снимка утверждённых документов, покрытия, миграций, health, логов и артефактов вынесены в Python CLI.
- Изменение тестов отменяет прежнее ревью. SHA кода отделён от SHA QA-отчёта.
- Покрытие проверяется по свежему JaCoCo XML. Пропущенный исходный файл блокирует результат.
- Liquibase XML master допускает подключение новой миграции без изменения существующих узлов.
- Пауза deploy сохраняет очередь. DevOps не меняет код после QA.
- Деплой связан с SHA кода и digest артефактов; G8 сверяет фактическое окружение.
- Утверждение связано со снимком требований, архитектуры, профиля и правил.
- GitHub sync учитывает все передаваемые поля. Добавлены правила восстановления после тайм-аута.
- Уточнены инженерные правила Spring, virtual threads и защиты от дублей.
- Добавлены 35 локальных тестов и GitHub Actions для Python 3.9 / 3.13.
- README переработан для продуктовых команд. Технические инструкции вынесены в руководство.

### Несовместимые изменения

- Нужны Python 3.9+ и Bash.
- `commands.backend.coverage_report` заменён на список `coverage_sources` с XML-отчётами.
- Staging требует `prepare_artifact`, `observe_artifact`, `status` и smoke.
- Для активных фич нужны новые `g2_snapshot` и `approved_snapshot`: повторите G2 и утверждение.
- Карточки получили поля версий QA/деплоя, исключения из декомпозиции и состояния GitHub sync.

[Переход на v2](.opencode/lib/README.md#обновление-существующего-проекта).

### Проверка и границы

35 тестов прошли локально. OpenCode 2.0.29 загрузил все 10 проектных агентов.
Полный цикл агентов, GitHub sync и staging с новыми проверками пока не подтверждён.
Файловая изоляция и транзакционное состояние доски не входят в эту версию.
