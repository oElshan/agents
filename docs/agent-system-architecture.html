Границы решения и источники
Схема отражает текущий агентный framework: один checkout и одна активная story; локальную доску изменяет только оркестратор. Гейты возвращают результаты проверок, а переходы выполняет оркестратор по инструкциям. Политики вызова инструментов не создают файловую изоляцию.
Пунктирные MCP-подключения ещё не настроены. Доступные tools, resources и prompts зависят от сервера. Atlassian Rovo MCP относится к Confluence Cloud / Jira Cloud; для Data Center нужен подходящий адаптер. Build, coverage и logs — результаты команд проекта, их хранение определяется профилем.
Основание: .opencode/framework.md, agents/*.md, lib/gates.py, skills/quality-gates и шаблоны project-setup.
